Free Ink Claude Buddy — Xteink

Flash the FreeInk-based desk-pet firmware straight from this page — X4, X3, or X4 Pro. No local toolchain needed.

This browser doesn't support Web Serial, which flashing over USB needs. Open this page in desktop Chrome or Edge instead — it won't work on Firefox, Safari, or mobile browsers. You can still flash manually; see manual flashing below.

1. Connect

Plug your Xteink device (X4, X3, or X4 Pro) into your computer with a USB-C cable.

2. Install

build info in the manifest, updated on every push to main

Click Connect, pick the device's serial port from the browser prompt, then Install. This erases the device and writes the full image (bootloader, partition table, and app) in one pass. The manifest carries builds for both chip families (ESP32-C3 for X4/X3, ESP32-S3 for X4 Pro) — ESP Web Tools reads the connected chip and picks the matching one automatically, so this one button covers all three boards.

If nothing shows up in the port picker, or the install stalls right after connecting: hold the BOOT button while plugging in the USB cable, then try Connect again. These boards use their native USB port for serial rather than a separate USB-UART bridge chip, and whether the browser can reset them into the bootloader automatically hasn't been confirmed on hardware yet — holding BOOT forces it into download mode regardless.

Manual flashing (fallback)

If the web installer doesn't work for your setup, download the merged image for your board from this build and flash it with esptool directly:

X4 / X3 (ESP32-C3):

pip install esptool
esptool --chip esp32c3 --port /dev/ttyACM0 write-flash 0x0 xteink.bin

Download xteink.bin (single merged image, flash at offset 0x0).

X4 Pro (ESP32-S3):

pip install esptool
esptool --chip esp32s3 --port /dev/ttyACM0 write-flash 0x0 xteink_x4pro.bin

Download xteink_x4pro.bin (single merged image, flash at offset 0x0).

Source

Built automatically from shelbeeely/claude-desktop-buddy (env:xteink for X4/X3, env:xteink_x4pro for X4 Pro) on every push to main — see README.md "Known limitations" for hardware details and known unverified assumptions.

Nothing typed or flashed here leaves your browser except what your browser sends directly to the connected device over USB — this page has no backend.
