Claude Desktop Buddy — Xteink X4

Flash the FreeInk-based desk-pet firmware straight from this page. No local toolchain needed.

This browser doesn't support Web Serial, which flashing over USB needs. Open this page in desktop Chrome or Edge instead — it won't work on Firefox, Safari, or mobile browsers. You can still flash manually; see manual flashing below.

1. Connect

Plug the Xteink X4 into your computer with a USB-C cable.

2. Install

build info in the manifest, updated on every push to main

Click Connect, pick the X4's serial port from the browser prompt, then Install. This erases the device and writes the full image (bootloader, partition table, and app) in one pass.

If nothing shows up in the port picker, or the install stalls right after connecting: hold the BOOT button (or short GPIO9 to GND) while plugging in the USB cable, then try Connect again. The X4 uses its native USB port for serial rather than a separate USB-UART bridge chip, and whether the browser can reset it into the bootloader automatically hasn't been confirmed on hardware yet — holding BOOT forces it into download mode regardless.

Manual flashing (fallback)

If the web installer doesn't work for your setup, download the merged image from this build and flash it with esptool directly: 

pip install esptool
esptool --chip esp32c3 --port /dev/ttyACM0 write-flash 0x0 xteink_x4.bin

Download xteink_x4.bin (single merged image, flash at offset 0x0).
